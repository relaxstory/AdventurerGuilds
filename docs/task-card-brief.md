## 二、遊戲概要

《冒險者公會》是 4 人桌遊，玩家經營冒險者公會，進行 8 輪。

- 玩家用公會行動**接取任務**（從公告欄 5 張公開任務中挑選，或直接拿任務牌庫頂的一張），再**派遣冒險者**去執行。
- 派遣時支付冒險者**薪資**，每名冒險者有**基礎骰數**（0～4 顆六面骰）。擲出的點數總和就是「結果值」，符合任務目標就成功，獲得金幣與聲望。
- 失敗時任務獲得**嘗試指示物**，下一次會比較容易。超過時限沒完成的任務會**逾期**，要付懲罰。
- 冒險者平均 1.4 顆骰子，每顆骰子的平均薪資約 1.4 金。
- 終局依**王國榮譽卡**評比勝負，例如「完成最多緊急任務」「完成最多聲望獎勵為負的任務」等，所以任務的類型、條件、標籤、聲望都會影響玩家的策略。
- 聲望可以是負數：**負聲望不是懲罰，而是「黑道路線」**，和正派路線一樣可以爭取榮譽。

## 五、數值規則

### 難度與目標

依「預期派遣的骰數」決定目標。預期的隊伍第一次嘗試約有 60～80% 的成功率。

| 難度 | ≥X（預期骰數） | ≤X（預期骰數） | X～Y（預期骰數，寬度＝Y−X） |
|---|---|---|---|
| 簡單 | ≥5～8（1～2 顆） | ≤4～5（1 顆） | 寬 4～5，例如 3～7、5～9（2 顆） |
| 普通 | ≥9～11（3 顆） | ≤6～8（2 顆） | 寬 5～6，例如 8～13（3 顆） |
| 困難 | ≥12～17（4～5 顆） | ≤9～10（3 顆） | 寬 6～7，例如 12～18（4 顆） |
| 極難 | ≥18～24（6 顆以上） | 不使用 | 寬 8～9，例如 18～26（6 顆） |

- 「≤X」代表派少數精銳、越安靜越好，預期骰數比同難度的「≥X」少，**不設計極難**。
- 計算金幣時，用表中括號內的預期骰數。
- **緊急任務**可以嘗試的時間短（約 2 個回合），難度降一級，或提高 1～2 金的獎勵。
- **永久任務**可以重複完成，難度可以高一級，但獎勵要偏低（只求打平）。

### 金幣獎勵

```
每次薪資 ＝ 預期骰數 × 1.4
期望薪資 ＝ 每次薪資 × 期望嘗試次數（簡單約 1.3、普通約 1.4、困難約 1.5、極難約 1.6）
金幣獎勵 ＝ 期望薪資無條件進位 ＋ 利潤
```

利潤依**聲望獎勵的絕對值**決定：|聲望| ≥ 2 加 0、|聲望| = 1 加 1、聲望 0 加 2。永久任務只求打平（利潤 0）。

| 難度 | 參考金幣 |
|---|---|
| 簡單 | 3～6 金 |
| 普通 | 6～9 金 |
| 困難 | 9～13 金 |
| 極難 | 13～20 金 |

### 聲望獎勵

| 路線 | 聲望 | 適合的劇情 |
|---|---|---|
| 正派 | +1～+2（極難可以 +3～+5） | 幫助王國、保護市民、行善 |
| 只為報酬 | 0 | 單純的工作、生意往來 |
| 黑道 | −1～−2（極難可以 −3～−5） | 走私、勒索、替黑道辦事、偷竊、見不得光的交易 |

負聲望**不是懲罰**，黑道任務的金幣獎勵也照上面的公式（用聲望的絕對值計算利潤）。

### 特殊規則（只能使用以下寫法）

> ⚠️ 目前規則引擎只支援第一種（直接完成）。其餘三種是預定新增的寫法，設計者確認後會統一實作，可以照常使用。

| 寫法 | 說明 |
|---|---|
| `若派遣具有[特質]的冒險者參與，可直接完成此任務。` | 特質只能用：[迅捷]、[潛行]、[聰明]、[巧手]、[巨大]、[護衛]、[飛行]、[善良]、[狡詐]、[貪婪] |
| `參與此任務的冒險者不能超過N名。` | N＝1～3，適合「≤X」或需要少數精銳的任務 |
| `參與此任務的冒險者至少需要N名。` | N＝2～4，適合「≥X」的大型任務 |
| `必須派遣具有[特質]的冒險者參與。` | 特質同上 |

其他寫法需要另外實作，請不要自創；有好點子可以寫在「設計備註」。

- 範例 A 的金幣：預期 2 顆 → 每次薪資 2.8 × 期望嘗試 1.4 次 ≈ 3.9，進位 4；|聲望| = 2 加 0 → 4 金。因為限 2 名冒險者，提高到 5 金。
- 範例 B 的金幣：預期 6 顆 → 每次薪資 8.4 × 期望嘗試 1.6 次 ≈ 13.4，進位 14；|聲望| = 3 加 0 → 14 金。有額外獎勵（灰燼），減 1 金 → 13 金。
