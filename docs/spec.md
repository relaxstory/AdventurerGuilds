## 1. 遊戲概要

玩家扮演冒險者公會的會長，招募冒險者、承接王國委託、經營公會。遊戲不直接比較財富或聲望，而是依照本局使用的**王國榮譽卡**判定勝負。金幣、聲望與任務都只是經營成果，王國榮譽才是勝利依據。

核心循環：

```
招募冒險者 → 承接任務 → 派遣冒險 → 擲骰完成任務 → 經營公會 → 爭奪王國榮譽
```

---

## 2. 遊戲設定

| 項目 | 規則 |
|---|---|
| 人數 | 固定 4 人 |
| 遊戲長度 | 基礎版 **8 輪**（速開版 4 輪只保留可能性，暫不設計） |
| 榮譽模式 | 王國評選／王國指派／王國競爭（見第 11 節） |
| 史詩任務 | 開局時選擇是否加入 |
| 骰子 | 六面骰（d6） |

## 3. 遊戲區域

### 3.1 公共區域

| 區域 | 說明 |
|---|---|
| 王國任務公告欄 | 固定公開 5 張任務 |
| 任務牌庫 | 從任務卡池隨機選 **50 張**組成本局的任務牌庫，用完後**不**重洗。8 輪共翻開 5 × 8 = 40 張，正常情況下不會抽完 |
| 任務棄置區 | 未接取的任務、逾期任務放這裡 |
| 綠龍酒館 | 固定公開 5 名冒險者，有排列順序 |
| 冒險者牌庫 | 未來冒險者卡池約 **100 張**，每局隨機選 **80 張**組成本局的冒險者牌庫。用完後**不**重洗 |
| 冒險者棄置區 | 退役的冒險者，例如輪末從酒館移除的冒險者 |
| 王國榮譽卡 | 依模式放置（見第 11 節） |

### 3.2 玩家公會區域

| 區域 | 說明 |
|---|---|
| 冒險者區 | 上限 **5 名**，不因公會升級改變。一支新兵小隊視為 1 名 |
| 任務暫存格 | 放本回合新接的任務。初始 1 格，升級後 2 格 |
| 正式任務區 | 回合格 [3]、[2]、[1]、[∞]。同一格可以放多張任務，沒有容量上限 |
| 任務完成區 | 已完成的任務，終局判定榮譽時使用 |
| 道具區 | 初始上限 3 格 |
| 資源 | 金幣、聲望 |

## 4. 開局設置

| 項目 | 初始值 |
|---|---|
| 金幣 | 5 |
| 聲望 | 0 |
| 冒險者 | 0 名 |
| 公會等級 | 初始公會 |

- 選擇遊戲長度、榮譽模式，以及是否加入史詩任務。
- **每局的牌庫都由卡池隨機組成**，所以每場遊戲遇到的卡片組合都不同：

  | 牌庫 | 組成方式 |
  |---|---|
  | 任務牌庫 | 隨機選 50 張洗混（不含史詩任務）。加入史詩任務時，依 10.2 的方式洗進牌庫下半部 |
  | 冒險者牌庫 | 隨機選 80 張洗混 |
  | 王國榮譽卡 | 隨機抽出本局模式需要的張數（見第 11 節） |

  卡池的範圍依開局模式而定，見第 17 節。卡池張數不足時全部使用。卡池只包含實裝狀態為「實裝」的卡片（測試模式另可加入「測試」的卡片）。
- 王國任務公告欄翻開 5 張任務，綠龍酒館翻開 5 名冒險者。
- 依榮譽模式抽取並放置王國榮譽卡。
- 🟡 **暫定**：首位起始玩家隨機決定。

## 5. 時間結構

```
一局 = 8 輪
一輪 = 4 位玩家各進行 1 個回合 → 輪末結算
```

- 每一輪的**起始玩家輪替**。
- 「回合開始」「回合結束」是個人時間點；「輪末」是全體時間點。
- 卡片上「本輪」的效果持續到該輪的輪末結算。

### 5.1 一個回合

| 順序 | 階段 | 內容 |
|---|---|---|
| 1 | 回合開始 | 🟡 **暫定**：觸發「回合開始時」的效果 |
| 2 | **公會階段** | 3 次公會行動（第 6 節） |
| 3 | **冒險階段** | 派遣冒險者執行任務（第 7 節） |
| 4 | **公會整理階段** | 處理任務時限、出售道具、公會升級（第 8 節） |
| 5 | 回合結束 | 🟡 **暫定**：觸發「回合結束時」的效果 |

## 6. 公會階段

每回合有 **3 次公會行動**，招募冒險者和接取任務共用。玩家可以只用其中一部分。

| 行動 | 消耗 | 限制 |
|---|---|---|
| 招募冒險者 | 1 次公會行動 | 招募不花金幣 |
| 接取任務 | 1 次公會行動 | 必須有空的任務暫存格 |

所以在沒有卡片效果的情況下：
- 初始公會每回合最多接取 1 項任務，升級後最多 2 項。
- 每回合最多招募 3 名冒險者。

### 6.1 招募與解僱

- 招募時，可以選擇替換公會裡一名現有冒險者，**不論公會是否已滿**。對被替換的冒險者來說，這稱為**解僱**。
- 被解僱的冒險者回到綠龍酒館，卡片另有寫明的除外。
- 解僱新兵小隊時，**整支小隊**回到綠龍酒館，佔酒館 1 格（見第 12 節）。

### 6.2 酒館的即時遞補

| 情況 | 處理 |
|---|---|
| 招募，沒有替換成員 | 酒館的冒險者依序往前補位，在末端翻開一名新冒險者 |
| 招募，並替換成員 | 被解僱的冒險者直接放進被招募者原本的位置，不從牌庫補牌 |
| 冒險者回到酒館 | 保留原有的成長與指示物 |

### 6.3 接取任務

從王國任務公告欄選一張任務，放進自己的任務暫存格。公告欄的空位在輪末才補，不會立即補。

🟡 **暫定**：公會階段也可以使用「公會階段」類的卡片能力，例如伊蓮娜製作藥劑。

## 7. 冒險階段

暫存格和正式任務區裡的任務，都可以在冒險階段執行。**新接的任務當回合就能執行。**

### 7.1 派遣流程

| 步驟 | 內容 |
|---|---|
| 1. 選擇任務 | 從暫存格或正式任務區選一張任務 |
| 2. 選擇冒險者 | 派遣一名或多名直立的冒險者，並將他們**橫置**（卡片效果另有規定的除外） |
| 3. 支付薪資 | **擲骰前**支付所有派遣冒險者的薪資，金幣不夠就不能派遣 |
| 4. 建立骰池 | 加總基礎骰數，再套用所有增減骰數的效果，得到最終骰池 |
| 5. 擲骰前宣告 | 例如怪盜雞德預言奇偶 |
| 6. 擲骰 | |
| 7. 擲骰後調整 | 重擲、轉動、移除骰子等 |
| 8. 計算總和 | 加總骰面，再套用總和修正，例如 ±X、兩倍 |
| 9. 判定 | 套用難度調整後，與任務條件比對 |
| 10. 結算 | 成功或失敗（見 7.4） |

**薪資只在派遣時支付。** 只發動能力、沒有被派遣的冒險者不用付薪資。例如瑞斯教授的【空間傳送】寫明「不視為派遣」，傳送加入任務的冒險者就不用付薪資。

### 7.2 任務條件與難度調整

| 條件 | 意義 | 難度調整 n |
|---|---|---|
| `≥ X` | 總和至少 X | 變成 `≥ X−n` |
| `≤ X` | 總和至多 X | 變成 `≤ X+n` |
| `X～Y` | 總和介於 X 到 Y | 玩家把 n 分配到兩端，擴大區間 |

- 難度調整一律往**對玩家有利**的方向。
- 骰子數值代表什麼（力量、安靜程度、速度等）由任務敘述決定，遊戲不另設屬性系統。

### 7.3 骰子操作

| 操作 | 定義 |
|---|---|
| 重擲 | 重新擲該顆骰子 |
| **轉動** | 不拿起骰子，把它往旁邊翻一面。可以轉成**相鄰的 4 個面**，不能轉成對面，也不能維持原本的點數。例如 2 可以轉成 1、3、4、6，不能轉成 5 |
| 移除 | 該顆骰子不計入總和 |

### 7.4 任務結算

| 結果 | 處理 |
|---|---|
| 成功 | 獲得金幣、聲望或其他獎勵，任務移到任務完成區 |
| 失敗 | 任務留在原位，放上 **1 枚嘗試指示物** |

- **每枚嘗試指示物等於難度調整 1**，會累加。
- 失敗不是懲罰，而是累積經驗的過程。

### 7.5 執行次數

- 一個冒險階段可以執行的任務數量不限，只要還有直立的冒險者和足夠支付薪資的金幣。
- **同一項任務在同一回合可以重複嘗試**，但每次都要重新派遣冒險者並支付薪資。後面派出的冒險者可能更不適合這項任務，但仍然可以嘗試。

## 8. 公會整理階段

| 順序 | 內容 |
|---|---|
| 1 | 正式任務區裡**原有**任務的時限 −1 |
| 2 | 處理逾期任務：移到任務棄置區，並支付逾期懲罰（8.2） |
| 3 | 暫存格裡沒完成的任務依類型移入正式任務區（8.1） |
| 4 | 出售道具（8.3） |
| 5 | 公會升級（8.4） |

先出售道具再升級，玩家可以用賣道具的錢升級。

### 8.1 任務時限

| 任務類型 | 移入位置 | 可執行的回合數（含接取當回合） |
|---|---|---|
| 一般 | [3] | 4 個回合 |
| 緊急 | [1] | 2 個回合 |
| 永久 | [∞] | 不會逾期 |
| 史詩 | [3] | 4 個回合，逾期視為失敗（見 10.2） |

時限減到 0 就算逾期。以一般任務為例：

| 時間點 | 位置 |
|---|---|
| 第 N 回合接取 | 暫存格 |
| 第 N 回合整理 | [3] |
| 第 N+1 回合整理 | [2] |
| 第 N+2 回合整理 | [1] |
| 第 N+3 回合整理 | 0，逾期 |

### 8.2 逾期懲罰

玩家從兩種懲罰中選一種**可以完整執行**的方式：

- **A. 扣金幣**：任務金幣獎勵的一半，無條件捨去。
- **B. 聲望往 0 移動**：一般任務移 1，緊急任務移 2。

數值為暫定，之後依試玩結果調整。

| 金幣夠付 A | 聲望 ≠ 0 | 處理 |
|---|---|---|
| 是 | 是 | 玩家二選一 |
| 是 | 否 | 執行 A |
| 否 | 是 | 執行 B |
| 否 | 否 | 金幣扣到 0 |

### 8.2.1 王國不信任

任務逾期時，依任務上有沒有嘗試指示物，判斷公會是否「接了任務卻完全沒有嘗試」：

| 逾期的任務 | 處理 |
|---|---|
| 有嘗試指示物 | 不增加不信任 |
| 沒有嘗試指示物 | 公會累積 **1 層王國不信任指示物** |

**設計意圖**：避免玩家故意接走任務、卡住別人卻不執行。這不是遊戲的核心玩法，所以只有**完全沒嘗試**的任務才會造成不信任；有嘗試過但失敗的任務不會。

| 項目 | 規則 |
|---|---|
| 與逾期懲罰 | **兩者都執行**。逾期懲罰是違約的代價，不信任是「完全沒嘗試」的額外處罰 |
| 最高階級 | 3 層 |
| 效果 | 完成任務時，金幣報酬依目前層數減少（見下表），最低為 0，不會倒扣 |
| 消除 | 每完成 1 項任務消除 1 層 |
| 處理順序 | 完成任務時，先用目前的層數扣報酬，再消除 1 層 |

報酬修正（數值暫定，試玩後調整）：

| 不信任階級 | 任務金幣報酬修正 |
|---|---|
| 0 | 無 |
| 1 | −1 金幣 |
| 2 | −2 金幣 |
| 3 | −3 金幣 |

### 8.3 出售道具

把道具區的道具出售，獲得該道具「售價」欄的金幣。卡片效果可能會改變售價，例如漢克．溫徹斯特。

### 8.4 公會升級

升級費用依**購買當下**的狀態判定。不是「曾經達到」就能一直享有。

| 條件 | 費用 |
|---|---|
| 累計完成 **4** 項以上任務 | 免費 |
| 聲望 ≥ 5 或 ≤ −5 | 3 金（半價） |
| 未達上述條件 | 7 金（原價） |

| 項目 | 初始公會 | 升級後 |
|---|---|---|
| 冒險者容量 | 5 | 5 |
| 任務暫存格 | 1 | 2 |
| 每回合公會行動 | 3 | 3 |
| 道具格 | 3 | 3（暫定，可能依實務調整） |

- 新增的暫存格從**下一個回合**開始使用。
- 設計預期：正常經營的玩家大約在第 4～5 輪可以免費升級。初始公會每回合最多接 1 項任務，所以第 N 輪結束時最多完成 N 項（見 `docs/task-difficulty.md` 第 7.2 節）。
- 聲望無論是 ≥5 還是 ≤−5 都有折扣，鼓勵玩家走「正派」或「地下」兩條路線。

## 9. 輪末結算

所有玩家都完成回合後，全體一起執行。

| 順序 | 內容 |
|---|---|
| 1 | 觸發「輪末結算時」的效果，例如巴克獲得金幣、瑪絲珂放置精工指示物 |
| 2 | 所有冒險者**重置**（轉回直立），有「不會於輪末重置」的除外 |
| 3 | 臨時衍生物銷毀，例如小嗶的【臨時機體】 |
| 4 | 「本輪」的效果結束 |
| 5 | 更新王國任務公告欄（10.1） |
| 6 | 更新綠龍酒館（10.1） |
| 7 | 如果是最後一輪，進入終局（第 11 節） |
| 8 | 起始玩家輪替給下一位 |

## 10. 市場與任務

### 10.1 市場輪替

兩個市場都在**輪末**更新，不是在每位玩家的回合結束時。

| 項目 | 王國任務公告欄 | 綠龍酒館 |
|---|---|---|
| 公開張數 | 5 | 5 |
| 輪替方式 | 全部換新 | 依序輪替 |
| 輪末處理 | 沒被接取的任務全部移到任務棄置區，再翻開新任務補滿 | 最前端 **2 名**移到冒險者棄置區，其餘往前補，再從末端翻開新冒險者補滿 |
| 牌庫用完 | 不重洗，空位留空 | 不重洗，空位留空 |

- 公告欄代表**不斷變化的委託需求**：看中的任務必須在當輪接下。
- 酒館代表**持續流動的人才市場**：中後期會變成公會之間交換人才的地方，玩家甚至可能重新招募自己以前培養過的冒險者。

### 10.2 任務類型

| 類型 | 說明 |
|---|---|
| 一般 | 時限 [3] |
| 緊急 | 時限 [1] |
| 永久 | [∞]，不會逾期 |
| 史詩 | 只能嘗試一次。不論成功或失敗都要翻面，結算背面效果；失敗時拿不到正面獎勵 |

#### 史詩任務

| 項目 | 規則 |
|---|---|
| 是否使用 | 開局時選擇是否加入 |
| 出現時機 | 洗進任務牌庫的**下半部**（第 26–50 張之間隨機），在中後期出現，但**不保證會出現** |
| 接取 | 和一般任務相同，花 1 次公會行動，需要空的暫存格 |
| 時限 | 移入正式任務區的 [3] |
| 嘗試次數 | 只能嘗試一次，**不適用** 7.5 的重複嘗試 |
| 逾期 | 視為失敗：翻面並結算背面效果，沒有正面獎勵 |

**設計意圖**：任務牌庫約 50 張，8 輪只翻開 40 張，最後約 10 張不會出現。這是刻意的設計，讓玩家無法確定某張任務一定會出現。史詩任務也可能不出現，為它提前準備冒險者的玩家，必須承擔它沒有出現的風險。

基礎版中，史詩任務出現的機率約為 60%（下半部 25 個位置中，有 15 個會在 8 輪內翻開）。

### 10.3 任務標籤

任務帶有標籤，例如陣營、外貌、能力、性格、技能、地形、特殊，供卡片效果和王國榮譽判定使用。地表與地下等分類屬於卡片設計細則，不放進核心規則。

## 11. 王國榮譽與終局

### 11.1 三種模式

所有模式使用同一套卡片，只是公開方式和分配方式不同。

| 模式 | 張數 | 4 人局 | 公開方式 | 判定對象 |
|---|---|---|---|---|
| 王國評選 | 人數 × 5 | 20 | 全部隱藏，終局揭示 | 所有玩家競爭每一張 |
| 王國指派 | 人數 × 3 | 12 | 每人 3 張，只有自己看得到 | 只判定持有者本人 |
| 王國競爭 | 人數 × 2 | 8 | 開局全部公開 | 所有玩家競爭每一張 |

- **王國評選**：玩家自由發展，終局的頒獎有驚喜感。
- **王國指派**：每位玩家有自己的目標，其他人可以從經營方向推測。
- **王國競爭**：目標公開，玩家之間的對抗最明顯。

**指派模式的「達成」**：排名型的卡片仍然要和全部玩家比較，持有者是第一名（含同分）才算達成。其他玩家就算比持有者高，也拿不到持有者手上的卡。

### 11.2 榮譽卡類型

| 類型 | 判定方式 | 狀態 |
|---|---|---|
| 排名型 | 比較玩家的經營成果，第一名取得 | 優先設計與測試 |
| 門檻型 | 達成指定數值或組合條件 | 後續設計 |

示意卡（名稱只是示意）：

| 名稱 | 條件 |
|---|---|
| 富甲一方 | 金幣最多 |
| 王國之光 | 聲望最高 |
| 暗影之主 | 聲望最低 |
| 使命必達 | 完成任務最多 |

其他討論過的方向：完成最多正向、負向或中立聲望任務。分類依照**任務獎勵的聲望是正數、負數或 0**。

### 11.3 設計原則

- 王國評選的是公會**最終的經營成果**，不是過程。
- 只使用終局時**桌面上看得到的資訊**判定，例如金幣、聲望、任務完成區、冒險者區、道具區。
- 不使用需要另外記錄的歷史數據，例如累計支付的薪資、曾經招募過的人數。

### 11.4 終局流程

```
最後一輪的輪末結算 → 揭示所有王國榮譽卡 → 逐張判定歸屬
→ 加上遊戲中獲得的額外榮譽卡 → 統計每位玩家的榮譽數 → 決定勝負
```

| 情況 | 處理 |
|---|---|
| 一張榮譽有多人同分 | 同分的玩家**都拿到** |
| 遊戲中直接獲得的榮譽卡，例如史詩任務的「諾特里堡壘英雄」 | 作為**額外榮譽分**，終局時加入計算 |
| 總榮譽數最多 | 獲勝 |
| 總榮譽數同分 | **共同勝利** |

## 12. 新兵小隊

適用於名字含「新兵」的冒險者。這是刻意設計的**收集新兵路線**。

| 項目 | 規則 |
|---|---|
| 組成 | 招募新兵時，可以讓他自成一支新小隊，或放到現有新兵小隊的**最上方或最下方** |
| 數量 | 一個公會可以有多支小隊 |
| 名額 | 一支小隊視為 1 名冒險者，占 1 個名額 |
| 順序 | 排好後不能改變 |
| 隊長 | 最上方的成員。只有隊長的【為了王國！】會生效 |
| 骰數 | 全隊成員的基礎骰數加總 |
| 薪資 | 只付**隊長**一人的薪資 |
| 一個冒險者 | 小隊在所有規則和效果中都視為**一個冒險者**。橫置、重置、銷毀、解僱都作用於整隊。例如銷毀小隊就是整隊銷毀 |
| 解僱 | **整支小隊**回到綠龍酒館，佔酒館 1 格 |
| 被其他玩家招募 | 招募者一次獲得整支小隊，小隊內部的順序不能改變。招募時可以選擇：<br>．作為一支獨立的小隊放入公會；<br>．把**整疊**放到自己現有新兵小隊的最上方或最下方，合併成一支小隊（放最上方時，招募來的小隊隊長成為新隊長） |
| 之後再招募新兵 | 照一般規則，新兵可以放到任何一支小隊的最上方或最下方 |
| 輪末從酒館移除 | 整支小隊進入冒險者棄置區 |

設計說明：新兵放上面還是下面，等於在決定要不要換隊長。大隊能用低薪資換來大量骰子，但不適合接 `≤X` 這種需要少骰子的任務。

## 13. 卡片狀態與通用機制

| 機制 | 說明 |
|---|---|
| 直立、橫置 | 派遣時橫置，輪末重置 |
| 翻面 | 雙面卡有正反兩面，翻面條件寫在卡片上。翻面時**保留**橫置或直立狀態與指示物，卡片另有寫明的除外（例如凱菲(B) 翻面時移除疲勞指示物） |
| 衍生物 | 由卡片效果產生的卡片，例如小嗶、彌的粉絲。**視為冒險者**，但**不佔冒險者容量**。被銷毀時回到衍生物牌組（如果有） |
| 銷毀 | 移出遊戲，等於冒險者死亡（見第 15 節） |
| 指定 | 能力選擇的目標。可能受到保護或免疫效果限制，例如威利、暗影 |
| 道具 | 可以消耗或出售。【獨特】與 [狀態] 道具見 16.3 |

### 13.1 指示物

指示物用來記錄卡片的**持續狀態、成長和任務經歷**，不是通用的消耗資源。

**通則**：指示物不會因為回合結束、輪末結算或冒險者重置而自動移除，除非專屬規則或卡片效果另有說明。

| 類型 | 放置位置 | 跨輪保留 | 跟隨對象 | 記錄內容 |
|---|---|---|---|---|
| 冒險者指示物（疲勞、精工等） | 冒險者卡 | ✓ | 冒險者 | 冒險者的成長 |
| 嘗試指示物 | 任務卡 | ✓ | 任務 | 任務的經歷 |
| 王國不信任指示物 | 玩家公會 | ✓ | 玩家 | 公會的信用 |

#### 冒險者指示物

指示物跟隨**冒險者**，不屬於玩家公會。所以玩家可以招募其他公會培養過的冒險者，並繼承他累積的成長。

| 情況 | 處理 |
|---|---|
| 玩家回合結束、輪末結算、冒險者重置 | 保留 |
| 冒險者翻面 | 保留，卡片另有寫明的除外 |
| 冒險者被放回綠龍酒館、被其他玩家招募 | 保留 |
| 卡片效果要求移除 | 依效果移除 |
| 冒險者被銷毀或進入冒險者棄置區 | 移除 |

#### 嘗試指示物

| 情況 | 處理 |
|---|---|
| 任務失敗 | 放置 1 枚 |
| 任務從暫存格移入正式任務區、時限減少、回合結束、輪末結算 | 保留 |
| 任務成功 | 移除（任務結算時，隨任務移入任務完成區） |
| 任務逾期棄置 | 移除（先用於判斷王國不信任，再移除） |

嘗試指示物的三種用途：
1. **降低難度**：每枚等於難度調整 1（見 7.4）。
2. **證明有嘗試過**：逾期時避免王國不信任（見 8.2.1）。
3. **作為能力的判定條件**：例如芙蕾雅．霜語的【永不言棄】。

#### 王國不信任指示物

見 8.2.1。

## 13A. 效果處理通則

| 項目 | 規則 |
|---|---|
| 同時觸發 | 多個效果同時觸發時，**當前玩家**先依自己決定的順序處理自己的效果，再依行動順序，由其他玩家各自決定順序處理自己的效果 |
| 「可以」與強制 | 寫「你可以……」的效果可以選擇不發動；沒有寫「可以」的是強制效果 |
| 主動能力 | 例如「橫置此冒險者：……」。只能在**自己的回合**使用，公會階段和冒險階段都可以，不花公會行動 |
| 觸發能力 | 「當……時」「每當……時」的能力，可以在任何玩家的回合觸發 |
| 「本輪」效果 | 持續到輪末結算的第 4 步（本輪效果結束） |

### 13A.1 道具使用

| 項目 | 規則 |
|---|---|
| 使用時機 | 「消耗此道具：……」的道具，可以在**自己回合的任何時間**使用 |
| 影響骰數的道具 | 例如強壯藥劑、縮小藥劑，只能在派遣流程「建立骰池」那一步使用 |
| 道具區已滿 | 獲得新道具時，只能**捨棄**道具騰出空間，**不能當下出售**。玩家需要自行管理道具區的取捨 |

### 13A.2 代價與後續效果

| 寫法 | 意義 | 無法執行時 |
|---|---|---|
| 「**X：**Y」（冒號前） | X 是**代價**，必須付得出來才能發動 | 付不出代價就不能發動 |
| 「Y，**然後** Z」 | Z 是**後續效果** | 能執行的部分就執行，不影響 Y 生效 |

例：B 的【無敵】寫「使該次銷毀無效，然後橫置此冒險者」。B 已經橫置時，銷毀仍然無效，只是不再橫置。

### 13A.3 指定與保護

只有寫「選擇一名」「指定」「目標」的效果才算**指定**。「所有」「每名」的全體效果不算指定。

| 保護類型 | 卡片寫法 | 被「選擇一名」的效果影響 | 被「所有」的效果影響 |
|---|---|---|---|
| **不能被指定**（類似魔法風雲會的 Hexproof） | 「無法被……指定」 | **不能被選擇** | 會受影響 |
| **不受某效果影響**（類似 Indestructible） | 「不能被橫置」「不會被銷毀」 | **可以被選擇**，但效果無效 | 不受影響 |

| 規則 | 內容 |
|---|---|
| 限制優先 | 「不能」永遠勝過「可以」。例：梭的和弦讓對方無法指定你的冒險者時，威利的「只能指定布魯斯與威利」也無法讓對方指定威利，對方的能力就沒有合法目標 |
| 沒有合法目標 | **主動能力**不能發動，也不能先付代價。**觸發能力**照樣觸發，但沒有效果（見 G16） |
| 選到不受影響的目標 | 目標合法，**代價照付，效果無效** |
| 轉移目標 | 例如威利、守門員小嗶，屬於限制或改變合法目標的效果 |

現有卡片分類：
- 不能被指定：暗影（不能被 [王國] 能力指定）、梭的【G大三和弦】。
- 轉移目標：威利、守門員小嗶。

設計備註：方葵是 [王國] 冒險者，所以她的【天羅地網】永遠無法指定暗影，呼應方葵長期追捕暗影卻抓不到的故事。這是刻意的設計。

### 13A.4 替代效果

替代效果是把一件即將發生的事改成另一件事，例如「改為……」「使……無效」。

| 規則 | 內容 |
|---|---|
| 只替代一次 | 同一件事只能被替代一次。已經被替代過的事件，不能再被其他替代效果改掉 |
| 「可以」與強制 | 寫「你**可以**改為……」的是選擇性的，玩家可以不套用，原本的事照常發生。沒寫「可以」的是強制的，必須套用 |
| 多個替代效果同時適用 | 由受影響卡片的擁有者選擇套用**其中一個**。只有在所有適用的效果都是選擇性時，才可以一個都不套用 |

例：

| 寫法 | 處理 |
|---|---|
| 瓦雷諾：「你**可以**改為銷毀此冒險者」 | 玩家可以不選，原本的冒險者照樣被銷毀 |
| 「改為銷毀此冒險者」（沒有「可以」） | 必須改為銷毀此冒險者 |
| 帶【無敵】的 [王國] 冒險者將被銷毀，瓦雷諾也在場 | 【無敵】是強制效果，所以玩家必須從【無敵】和瓦雷諾中選一個套用。通常會選【無敵】 |

### 13A.5 選項式效果

例如里諾的「該玩家選擇一項」：玩家必須選一個**可以完整執行**的選項；所有選項都無法執行時，什麼也不發生。

### 13A.6 設計備註：必勝、犧牲、無敵

設計中的一對冒險者：

- **A**【必勝】參與任務時，無視任務條件直接完成，每輪限一次。【犧牲】參與任務後，銷毀 1 名參與該任務的冒險者，由 A 的擁有者選擇，可以選 A 自己。
- **B**【無敵】將被銷毀時，使該次銷毀無效，然後橫置此冒險者。

A 和 B 一起出任務時，可以每輪一次無代價地完成任務：【犧牲】選擇 B，【無敵】使銷毀無效。這是**刻意設計的組合**。

## 16. 通用判定規則

由卡片檢查（`docs/card-review.md`）整理出的規則。

### 16.1 任務與擲骰

| # | 項目 | 規則 |
|---|---|---|
| G2 | 「此冒險者完成任務」 | 此冒險者**參與**了一項被完成的任務 |
| G3 | 「任務結算時」 | 指**你的**任務，成功或失敗都算。只在成功時觸發的效果寫「完成任務時」 |
| G4 | 骰面總和與結果值 | **骰面總和**：骰子點數加總。**結果值**：套用總和修正（±X、兩倍等）後的數值。判定成敗使用結果值 |
| G11 | 效果疊加 | 不同卡片的效果會疊加。例如呂昶和凱蒂一起參與任務時，難度共調整 2 |
| G12 | 薪資下限 | 薪資最低為 0 |
| G14 | 派遣中加入冒險者 | 「加入此次任務」類的能力（例如瑞斯教授），在派遣流程第 2 步（選擇冒險者）之後、第 4 步（建立骰池）之前使用 |

### 16.2 指定與效果範圍

| # | 項目 | 規則 |
|---|---|---|
| G5 | 「一名冒險者」的範圍 | 指**任何公會**冒險者區裡的冒險者，不含綠龍酒館。只限自己的，卡片要寫「你公會中的」 |
| G6 | 指定 | 只有**發動能力當下**做的選擇才是指定。其他選擇都屬於效果內容，不是指定。例如布魯斯讓對手「橫置自己的一名冒險者」，對手做的選擇不是指定，所以不受威利、梭的保護影響 |
| G16 | 觸發能力的選擇 | 觸發能力在**觸發時**做的選擇也是指定。沒有合法目標時，觸發能力照樣觸發，但**沒有效果**。例如所有冒險者都受梭保護時，狂人里諾的翻面效果觸發了，但沒有效果 |

### 16.3 道具

| # | 項目 | 規則 |
|---|---|---|
| G7 | 【獨特】道具 | 整場遊戲**只有一份**。已經存在時，再次執行相同的行動也拿不到。被銷毀後就不會再出現 |
| G8 | [狀態] 道具 | **不佔道具格**，**不能捨棄也不能出售**。例如梅里妲的注視、火爪的信念 |

### 16.4 資源與聲望

| # | 項目 | 規則 |
|---|---|---|
| G9 | 金幣不足 | **強制**支付的金幣不夠時，扣到 0 為止。**選擇性**支付（包括代價）付不出來就不能執行 |
| G13 | 聲望下降 | 聲望數值**變小**就是下降，也就是往黑道方向經營。例如 −2 變 −3 是下降；−3 變 −2 是往正派方向，屬於上升 |

### 16.5 衍生物

| # | 項目 | 規則 |
|---|---|---|
| G1 | 衍生物 | 視為冒險者，會觸發「冒險者被銷毀」等效果（例如艾里克）。**不佔冒險者容量**。被銷毀時回到衍生物牌組（如果有） |

### 16.6 翻面

| # | 項目 | 規則 |
|---|---|---|
| G15 | 菲特造成的翻面 | 會觸發「當此冒險者被翻面時」的效果。翻回來時也會觸發 |

菲特的範例：

| 情況 | 結果 |
|---|---|
| 忠誠的勇者 → 賴皮的勇者 | 觸發額外招募，但酒館裡沒有賴皮的勇者，所以沒有效果 |
| 里諾 → 狂人里諾 | 執行狂人的翻面效果；能力結束後翻回里諾 |
| 狂人里諾 → 里諾 | 翻面沒有效果，但可以使用里諾的橫置能力；能力結束後翻回狂人時，會再觸發一次狂人的效果 |

## 17. 基礎版與擴充系列

### 17.1 結構

| 類別 | 說明 | 例子 |
|---|---|---|
| **基礎版** | 各式各樣的角色與任務，彼此有聯動，但不會非常強烈 | 目前大部分卡片 |
| **擴充系列** | 聯動性很強、需要整組一起出現才能發揮的卡片，作為基礎版之外的擴充 | 擴充一：新兵小隊；擴充二：青蛙合唱團 |

一個擴充系列可以包含冒險者、任務、道具、衍生物。每張卡片**最多屬於一個**擴充系列。

擴充系列的卡片來自**同一段故事或世界觀**。擴充裡的任務在背景敘述上和擴充的冒險者有關，標籤也比較貼合這些冒險者，但**不限定**只有這些冒險者才能完成，只是比較適合。

**擴充系列沒有專屬的王國榮譽卡。** 專門為某個擴充設計的榮譽，只有拿到那組卡片的玩家有機會達成，會變成先搶先贏，所以不採用。王國榮譽卡在所有模式下都使用同一個卡池。

### 17.2 開局模式

| | 預設模式 | 擴充模式 |
|---|---|---|
| 選擇 | 不選擴充 | 房主開房時勾選**最多 2 個**擴充系列 |
| 冒險者、任務 | 基礎版與所有擴充系列的卡片混在一起，隨機選出 80 張冒險者、50 張任務 | 勾選的擴充系列**整組放入**，剩下的名額隨機補滿，總數仍是 80 張冒險者、50 張任務 |

例：勾選「新兵小隊」時，7 張新兵全部放進冒險者牌庫。預設模式下也可能隨機抽到幾張新兵，但不保證整組出現。

擴充模式中，補滿名額的方式由房主選擇：

| 選項 | 補滿名額時使用的卡片 |
|---|---|
| 勾選「只從基礎版補滿」 | 只從**基礎版**選，未勾選的擴充系列不會出現 |
| 不勾選 | 從**所有剩餘的卡片**（基礎版＋未勾選的擴充系列）隨機選 |

### 17.3 卡片編號

卡片編號的前三碼（例如 `STD`）用來區分基礎版與擴充系列。目前新兵小隊、青蛙合唱團仍使用 `STD` 編號，正式整理卡表時會改成對應擴充的編碼。

擴充系列的編碼為**依該擴充英文名稱取的 3 個英文字母**，不使用 `EX1` 這類流水號。試算表中目前的 `EXP`、`EX1`、`S2`、`S3` 只是暫時區分不同系列的預設代碼，沒有正式意義，之後會改掉。

### 17.4 與史詩任務的關係

史詩任務**不屬於**擴充系列，仍由開局時的「是否加入史詩任務」選項控制（見 10.2）。

## 附錄：數位版的初步考量

這些不屬於規則，供之後的開發規劃參考。

- **人數**：規則固定 4 人。第一版建議支援「4 個真人開局」和「一個人操控多個公會」（方便測試）；AI 補位放到後期，可以和平衡模擬工具共用同一套邏輯。
- **卡片實體**：每張冒險者卡要記錄自己的狀態，例如指示物、正反面、橫置。換了主人或回到酒館時，狀態要跟著那張卡走。
- **效果系統**：試算表的「技能框架」加上 X/Y 參數，可以直接對應到程式模板。獨特技能另外寫腳本，例如學舌鳥、菲特、瑪絲珂工作室。
- **跨玩家互動**：能力可能要求另一位玩家做選擇，例如布魯斯、里諾，系統要能暫停並等待該玩家回應。
- **亂數**：擲骰由伺服器產生，防止作弊，也方便重播。
