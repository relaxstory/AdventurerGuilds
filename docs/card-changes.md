# 卡片文字修改清單

> 依據：規則規格書（`docs/spec.md`）第 15、16 節，以及卡片規則檢查（`docs/card-review.md`）
> 對象：Google 試算表「卡片設計表」
> 每一項的「原文片段」都已經和試算表的現有內容比對過，可以直接搜尋取代。
>
> ✅ **第一節的 #1–#31 已全部完成**，並已逐格比對確認，沒有其他儲存格被改動。
> 🆕 **#32 為後來新增，尚未修改。**

## 修改方式

- 「欄位」是試算表的欄名：「冒險者」分頁的**技能**欄、「衍生物」分頁的**特徵**欄、**基礎骰數**欄。
- 只取代「原文片段」那一段，同一格的其他文字保持不變（包括換行）。
- 「提取用」分頁不用改。

## 三、給其他 AI 助理的指示範本

```
請依照以下修改清單，修改 Google 試算表「卡片設計表」：
https://github.com/relaxstory/AdventurerGuilds/blob/main/docs/card-changes.md

規則：
1. 只修改「一、可以直接修改」中尚未完成的項目，「二」不需要修改。
2. 每一處只把「原文片段」取代成「修改為」，同一格的其他文字和換行保持不變。
3. 找不到原文片段時，不要猜測修改，直接回報是哪一項。
4. 不要修改「提取用」分頁。
5. 完成後列出每一項的結果：已修改／找不到原文／略過。
```
