# 卡片規則檢查 v1

> **第一節的通用規則已經決定，寫進規格書第 16 節。** 第二節的卡片修改建議也都已採用，請在試算表中修改卡片文字。

> 依據：規則規格書 v0.3 之後的版本（`docs/spec.md`）
> 範圍：冒險者 61 張（含雙面）、衍生物 9 張、道具 16 張、任務 22 張
> 目的：找出依現行規則**無法執行**、**有歧義**或**數位化不容易實作**的卡片

### 嚴重度

| 標記 | 意義 |
|---|---|
| 🔴 | 依現行規則**無法執行**，或結果明顯不合理 |
| 🟠 | **有歧義**，不同玩家可能有不同解讀，需要補規則或改卡片文字 |
| 🟡 | 可以執行，但**數位化較複雜**或有平衡上的觀察 |

## 一、缺少的通用規則

這些問題影響多張卡片，建議補進規格書，而不是逐張修改卡片。

| # | 問題 | 影響的卡片 | 建議 |
|---|---|---|---|
| G1 | **衍生物算不算冒險者？** 算不算冒險者容量？被銷毀後去哪裡？ | 小嗶（8 張）、彌的粉絲、艾里克 | 衍生物**視為冒險者**、**佔用容量**；容量已滿時不能創造。銷毀時回到衍生物牌組 |
| G2 | **「此冒險者完成任務」的定義** | 萊利、伊格納斯、艾伯特、老約翰、戈拉古斯 | 此冒險者**參與**了一項被完成的任務 |
| G3 | **「任務結算時」指誰的任務？失敗也算嗎？** | 巴爾、艾妲、雞德、阿絲特拉、阿特薩 | 指**你的**任務；成功或失敗都算結算。只在成功時觸發的效果寫「完成任務時」 |
| G4 | **「骰面總和」和「最終結果值」的差異** | 阿絲特拉、阿特薩、雞德、嗚嘎、希氏炸藥、喀嘣小嗶 | 骰面總和＝骰面加總；**結果值**＝套用總和修正（±X、兩倍）後的數值。判定成敗用結果值 |
| G5 | **效果裡的「一名冒險者」範圍** | 巴克、方葵、紅斑菌菇、精力藥劑、飛天小嗶 | 指**任何公會**的冒險者區中的冒險者，不含酒館。只限自己的要寫「你公會中的」 |
| G6 | **對手依你的能力選擇「自己的」冒險者，算不算被指定？** | 布魯斯、里諾 × 威利、梭 | **不算指定**。只有能力的使用者做的選擇才算指定 |
| G7 | **【獨特】道具的定義** | 父親的家書、荊棘玫瑰、梅里妲的注視、戈拉古斯的手稿 | 同一場遊戲中只能存在 1 張；已經存在時不能再獲得 |
| G8 | **[狀態] 道具佔不佔道具格？可以捨棄或出售嗎？** | 梅里妲的注視、火爪的信念 | [狀態] **不佔道具格**，**不能捨棄也不能出售**。否則梅里妲的注視可以直接丟掉 |
| G9 | **強制支付的金幣不夠時** | 過勞死凱菲（10 金） | 強制支付時金幣扣到 0 為止（和逾期懲罰一致）；選擇性支付則付不出就不能執行 |
| G10 | **效果影響小隊時，是整隊還是一名成員？** | 犧牲、史詩任務背面、梅里妲的注視、里諾、布魯斯 | 小隊視為 1 名冒險者：橫置、重置影響整隊。**銷毀**時由擁有者選 1 名成員銷毀，小隊其餘保留（若隊長被銷毀，下一名成為隊長） |
| G11 | **同名效果是否疊加** | 呂昶與凱蒂的【追捕默契】 | 不同卡片的效果**會疊加**，所以兩人一起出任務時難度調整共 2。若設計意圖是 1，需要改卡片 |
| G12 | **薪資最低是多少** | 哈克貝里、方庚 | 薪資最低為 0 |
| G13 | **「聲望下降」的定義** | 梅里妲的注視、新兵席德 | 聲望數值**變小**就算下降。所以負聲望玩家從 −3 變 −2 不算下降，從 −2 變 −3 才算 |
| G14 | **派遣流程中可以使用主動能力的時機** | 瑞斯、學舌鳥 | 在派遣流程第 2 步（選擇冒險者）之後、第 4 步（建立骰池）之前，可以使用「加入此次任務」類的能力 |
| G15 | **菲特造成的翻面會不會觸發「當被翻面時」** | 菲特 × 里諾、賴皮勇者 | **會觸發**。翻回來時也會觸發 |

## 二、逐張檢查

### 🔴 無法執行或明顯不合理

| 卡片 | 問題 | 建議 |
|---|---|---|
| 「爆炸頭」傑米【看我的傑作！】 | 沒有寫發動時機或代價，不知道什麼時候可以用 | 改成「橫置此冒險者：創造……」或寫明觸發時機 |
| 戈拉古斯的手稿 | 目前沒有任何卡片會「銷毀【獨特】道具作為代價」，這張道具沒有用途。「提取用」和「道具」兩頁的文字也不一樣（「作為代價時」vs「將被銷毀時」） | 統一文字。若採用「將被銷毀時」，就能保護梅里妲的注視以外的獨特道具 |
| 戈拉古斯．泥鏟 | 觸發條件是 [遺跡] 任務，但任務標籤裡沒有 [遺跡] | 新增標籤，或改成現有標籤 |
| 薩姆．火爪 × 火爪的信念 | 要累積 3 個信念才有最大效果，但道具區只有 3 格 | 依 G8 讓 [狀態] 不佔道具格即可解決 |
| 梅里妲的注視 | 持有者可以直接捨棄或出售（售價 0），懲罰形同無效 | 依 G8 處理 |
| 過勞死凱菲【終於可以一直上班了！】 | 「必須派遣此冒險者參與」：凱菲橫置或付不出薪資時怎麼辦？玩家是否因此無法執行任何任務？ | 建議改成「若可以，必須……」：凱菲無法參與時，限制解除 |

### 🟠 有歧義

| 卡片 | 問題 | 建議 |
|---|---|---|
| 新兵 貝琪 | 「擲骰結果可以 ±1」：是一顆骰子 ±1，還是結果值 ±1？ | 寫清楚，例如「結果值 ±1」 |
| 喀嘣小嗶 | 「總和可加減 X」：只能剛好 ±X，還是 0 到 X 之間任選？ | 寫清楚，例如「結果值可以調整至多 ±X」 |
| 守門員小嗶 | 「發動能力的玩家擲骰」：擲幾顆？ | 寫明「擲 1 顆骰子」 |
| 方葵【天羅地網】 | 技能框架寫「直立冒險者」，卡片文字沒寫「直立」 | 統一。橫置已經橫置的冒險者沒有意義，建議加上「直立」 |
| 新兵 席德 | 「額外降低 1 聲望」：是聲望 −1，還是往 0 移動？ | 建議統一：「降低」一律是 −1，「往 0 移動」另外寫明 |
| 「賭徒」馬文 | 只寫了「至少 X」和「至多 X」，`X～Y` 的任務能不能用？ | 寫明 `X～Y` 不能使用，或補上規則 |
| 「青蛙合唱團」菈 | 「指定的目標數量 +1」：哪些能力算？布魯斯的「選擇一名其他玩家」也算嗎？ | 建議限定為「選擇一名冒險者」的能力，或改成更明確的效果 |
| 「青蛙合唱團」蕾 | 「將 1 個任務的時限 +1」：可以選別人的任務嗎？ | 加上「你的」 |
| 小丑小嗶 | 「可重置 X 個冒險者」：誰的冒險者？ | 加上「你公會中的」 |
| 學舌鳥 | 複製的效果裡若有「此冒險者」，指的是原卡還是學舌鳥？例如複製巴克「然後將此冒險者翻面」 | 建議「此冒險者」改指學舌鳥。學舌鳥沒有背面，所以這類效果「無法完整執行」，不能複製 |
| 「天才」瑪絲珂 | 小嗶被銷毀後回到哪裡？瑪絲珂被解僱回酒館時，工作室跟著她嗎？ | 小嗶銷毀後回到衍生物牌組（工作室會越用越少，一場最多 3 次）。工作室跟著瑪絲珂 |
| 史詩任務背面 | 參與者少於 2 人時，「銷毀兩位」怎麼處理？ | 能銷毀幾位就銷毀幾位 |
| 那個忠誠的勇者 | 勇者被解僱 → 回酒館翻面 → 賴皮勇者觸發「招募至你的公會」。「你」是誰？ | 「你」是讓他回到酒館的玩家，也就是解僱他的人 |

### 🟡 可以執行，但較複雜或值得注意

| 卡片 | 觀察 |
|---|---|
| 學舌鳥 | 數位化最複雜的卡：需要把每個主動能力的「：」後效果拆成可以單獨執行的單位，並判斷「能否完整執行」 |
| 「歧路觀測者」菲特 | 需要記錄暫時翻面的狀態，輪末再翻回來；翻面觸發會連鎖（G15） |
| 守門員小嗶 | 需要在對手發動能力的中途插入「轉移目標 → 擲骰 → 可能取消」的流程 |
| 「青蛙合唱團」7 張 | 和弦需要持續檢查公會裡有哪些成員，數位化不難，但實體遊戲要記的事情很多 |
| 艾里克 × 小嗶、彌的粉絲 | ✅ 已決定：【最後的禱言】改為「每當有**非衍生物的**冒險者被銷毀時」，避免衍生物成為穩定的聲望來源 |
| 方庚 | 派遣時永遠不橫置，同一回合可以一直派遣，每次付 3 金。搭配重複嘗試規則很強 |
| 凱菲 | 派遣不橫置，同一回合可以多次派遣，快速累積疲勞，幾回合內就會翻面 |
| 里諾 | 對手選「翻面」時，里諾的擁有者得到更強的狂人里諾，而且對手仍要橫置一名冒險者，所以選項 2 幾乎總是比選項 1 差。如果這是刻意的（「不配合就更糟」），可以保留 |
| 富豪巴克、布萊克、巴爾、艾妲 | 「不會於輪末重置」的冒險者一旦橫置就一直保持橫置，可以搭配精力藥劑、汐等重置效果反覆使用 |
| 瑞斯教授 | 派遣時會被橫置，所以如果他自己參與任務，就無法再付「橫置此冒險者」的代價。實際用法是「瑞斯不出任務，把其他冒險者送進任務」，送進去的冒險者不付薪資、也不橫置，之後還能再被派遣 |
| 比爾．溫徹斯特 | 小麥在「回合結束時」獲得，晚於公會整理階段的出售，所以最快要下一回合才能賣 |
| 紅斑菌菇 | 「選擇一名冒險者」可以選對手的冒險者，讓它輪末無法重置。若不想讓它成為干擾道具，要限定「你的」 |

## 三、資料問題

| 問題 | 說明 |
|---|---|
| 缺少的標籤 | [遺跡]、[火焰]、[動物] 被卡片引用，但不在任務標籤表 |
| 標籤括號 | 偷偷摸摸小嗶寫「具有【潛行】的任務」，標籤應該用 [潛行] |
| 缺少編號 | 《王座之側的荊棘玫瑰》沒有道具編號；多數任務沒有編號和數值 |
| 用詞 | 見規格書 15.3 的修改清單；另外漢克寫「移除至多 2 個 [農產品]」，建議統一為「銷毀」或「消耗」 |
| 王國榮譽 | 分頁仍是空的 |
