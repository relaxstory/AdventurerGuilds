## 一、技能模板清單

> 由 `tools/skill_templates.py` 產生，請勿直接編輯本檔。
> 每張卡的模板與參數見 `data/skill-mapping.csv`。
> 本清單與對照表由 Claude 維護，設計者**不需要**在試算表填寫模板代碼（見 `docs/digital-spec.md` 第 7 節）。

### 設計說明

- 每個技能拆成一個或多個**子句**，每個子句對應一個模板。例如富豪巴克的【坐著數錢就好】＝ `NO_ROUND_RESET` ＋ `ROUNDEND_IF_TAPPED_GAIN`。
- **主動能力**＝ `COST`（代價）子句＋一個或多個效果子句。
- **條件**子句（例如青蛙合唱團的和弦 `COND_HAS_CARDS`）控制同一技能的後續子句是否有效。
- 每個模板最多 3 個參數：X、Y、Z。多個值用「／」分隔。
- 新卡片只要能用現有模板組合，就**不需要寫程式**。

#### 參數的寫法

| 參數類型 | 寫法 |
|---|---|
| 數量 | 整數，可為負數，例如 `2`、`-1` |
| 依指示物計算 | 指示物名稱，例如 `精工`；取一半並無條件捨去寫 `精工/2` |
| 資源 | `金幣` 或 `聲望` |
| 任務條件 | 空白＝任何任務；標籤如 `[森林]`；任務類型如 `緊急`、`永久`；或 `有嘗試指示物` |
| 卡名、道具名稱 | 和試算表的名稱完全相同 |

### 統計

- 模板共 **110** 個，涵蓋 **88** 張卡片、**194** 個子句。
- 被 2 張以上卡片共用的模板：**26** 個。
- 特殊模板（需要專門程式）：**7** 個。

### 類型

| 類型 | 說明 | 數量 |
|---|---|---|
| 條件 | 控制同一技能的後續子句是否有效，或限制使用時機 | 2 |
| 代價 | 主動能力冒號前的部分，必須付得出來才能發動 | 2 |
| 常駐 | 只要卡片在場就持續有效 | 36 |
| 觸發 | 在特定時機自動觸發（寫「可以」的是選擇性） | 41 |
| 效果 | 通常接在代價之後，描述主動能力做什麼 | 20 |
| 關鍵字 | 代表一整套規則，詳細內容寫在規格書 | 2 |
| 特殊 | 機制獨特、無法用一般模板組合，需要專門的程式 | 7 |
