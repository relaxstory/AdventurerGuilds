# 王國榮譽卡候選清單 v3

> 依據：規格書第 11 節。只使用**終局時桌面上看得到的資訊**判定，不使用需要另外記錄的歷史數據。
> 本清單是候選方案，名稱與條件都可以修改，由設計者挑選後填入試算表。
> 每局只從卡池抽出一部分使用（王國評選約 6 張、王國指派 12 張、王國競爭 6 或 8 張，見規格書 11.1）。卡池至少 12 張。

---

## 1. 可以用來評選的終局資訊

| 區域 | 可以比較的項目 |
|---|---|
| 資源 | 金幣、聲望（可正可負） |
| 任務完成區 | 完成數量；依任務類型（一般、緊急、永久、史詩）；依條件（≥、≤、X～Y）；依標籤；依聲望獎勵的正負；單一任務的目標值 |
| 正式任務區 | 未完成的任務、任務上的嘗試指示物 |
| 冒險者區 | 人數；種族、職業、特質；基礎骰數總和；薪資總和；新兵小隊人數；冒險者身上的指示物 |
| 道具區 | 道具數量、售價總和 |
| 其他 | 王國不信任層數、公會等級 |

## 3. 通用判定規則（已確認）

| # | 規則 |
|---|---|
| 1 | 「最多、最高」類的榮譽，數值必須**大於 0** 才能取得，0 不算。例如本局沒有人完成緊急任務，「分秒必爭」就沒有人拿到 |
| 2 | 沒有人符合條件時，該張榮譽不頒發 |
| 3 | 計算冒險者人數時，**新兵小隊視為 1 名冒險者**（一整隊不會算成 7 人），**衍生物不計入** |
| 4 | 雙面卡依**目前朝上的那一面**判定種族、職業、特質。例如狂人里諾是狂戰士，不是斥侯 |
| 5 | 同分的玩家都拿到（規格書 11.4） |

## 4. 設計說明

- **相關性**：「使命必達」和大部分任務類榮譽有關聯，完成很多任務的玩家容易同時拿到好幾張。王國評選模式抽 20 張，影響會比較明顯；王國競爭模式只抽 8 張，影響較小。
- **不設擴充專屬的榮譽**：依規格書第 17 節，擴充系列沒有專屬榮譽卡，避免只有拿到特定卡片的玩家才有機會達成。原本的「鐵血軍團」（新兵小隊人數最多）因此移除。
- **依賴卡池的榮譽**：「王國之友」「輕手輕腳」「恰到好處」「持之以恆」需要本局有對應的任務。卡池隨機組成時，這些榮譽可能沒有人拿到（依通用規則 #1、#2 不頒發）。
- **「地表／地下」任務**：原始設計提過的方向，等任務的地表、地下分類確定後再加入。
- **門檻型榮譽**：依規格書，留待之後設計。
