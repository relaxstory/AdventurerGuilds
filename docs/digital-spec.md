# 《冒險者公會》線上版功能規格

> 版本：v0.1（第一版範圍）
> 遊戲規則見 `docs/spec.md`，本文件只描述線上版的功能。

---

## 1. 第一版範圍

| 項目 | 決定 |
|---|---|
| 對局人數 | 4 人 |
| 帳號 | 不需要 |
| 開局方式 | 建立房間、分享連結 |
| 平台 | 網頁優先（桌面瀏覽器），手機可以打開但不針對小螢幕設計 |
| 時間限制 | 不設 |
| 介面語言 | 繁體中文 |

**第一版不做**：帳號、戰績、AI 對手、觀戰、手機版介面、速開版。

---

## 2. 房間

| 項目 | 規格 |
|---|---|
| 建立 | 房主建立房間，取得房間連結和房間碼 |
| 設定 | 房主設定榮譽模式（王國評選／王國指派／王國競爭），以及是否加入史詩任務 |
| 加入 | 打開連結或輸入房間碼，輸入暱稱後入座 |
| 開始 | 4 個座位都坐滿後，由房主開始遊戲 |
| 關閉 | 連續 **7 天**沒有活動後自動關閉。所以房間狀態必須存進資料庫，伺服器重啟也不會遺失 |

---

## 3. 斷線重連

| 情況 | 處理 |
|---|---|
| 同一個瀏覽器重新打開 | 瀏覽器記住座位，打開連結就自動回到原本的座位 |
| 換裝置或清除瀏覽器資料 | 輸入房間碼後，畫面列出目前斷線中的座位，選擇自己的座位回到遊戲 |

說明：第二種方式理論上可以冒充其他玩家。第一版是朋友之間開房，接受這個風險。

---

## 4. 遊戲進行

| 項目 | 規格 |
|---|---|
| 規則判定 | 所有規則判定和擲骰都在伺服器處理，玩家無法作弊 |
| 隱藏資訊 | 只傳給有權看的玩家，例如王國指派模式的榮譽卡、牌庫的順序 |
| 等待他人選擇 | 效果要求其他玩家做選擇時（例如布魯斯、里諾），整局暫停等待那位玩家 |
| 遊戲紀錄 | 顯示每一步誰做了什麼、擲出幾點 |

### 4.1 反悔

**原則：只要還沒有揭露新的資訊，就可以反悔。**

| 可以反悔 | 不能反悔 |
|---|---|
| 選錯冒險者、選錯任務、還沒確認的選擇 | 擲骰之後 |
| | 翻開牌庫的牌之後 |
| | 其他玩家已經依此做出選擇之後 |

連帶的影響：
- 沒有替換成員的招募會讓酒館從牌庫補一張新的冒險者，屬於「翻開牌庫」，所以**不能反悔**。
- 替換成員的招募不會翻開牌庫（被解僱的冒險者直接放進空位），所以**可以反悔**。
- 介面在執行「不能反悔」的操作之前，會提醒玩家確認。

### 4.2 卡住時的處理

不設時間限制。有玩家長時間沒有動作時：

| 版本 | 處理 |
|---|---|
| 測試版 | 房主可以替該玩家**跳過目前的回合**或選擇 |
| 正式版 | 之後再決定 |

## 5. 測試模式

**放入第一版**：一個人在同一個畫面操作 4 個公會，用來測試規則與平衡。
