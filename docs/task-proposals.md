## 2. 收支檢查

目標：完成任務後，金幣獎勵**扣除付出的薪資**可以打平或有利潤。

- **每次薪資**＝預期骰數 × 1.4（冒險者每顆骰子的平均薪資）。
- **期望薪資**＝每次薪資 × 期望嘗試次數。失敗會再派一次、再付一次薪資，每次失敗累積的嘗試指示物會讓下一次更容易。史詩任務只能嘗試一次。
- **期望利潤**＝金幣獎勵 − 期望薪資。聲望是額外收益，不計入。

金幣的訂法：期望薪資無條件進位，再依聲望獎勵加上利潤：聲望 ≥ 2 加 0（聲望本身就是收益）、聲望 1 加 1、聲望 0 加 2、聲望為負加 3（補償名聲損失）；永久任務可以重複完成，只求打平。

## 4. 設計說明

- **標籤**只使用目前已有的標籤，不使用預留標籤 [遺跡]、[火焰]、[動物]。標籤依任務的故事選擇，同時讓擁有相關能力的冒險者有發揮空間，例如 [巧手] 對應伊格納斯、艾伯特；[聰明] 對應羅德教授、莎莉、嗚嘎；[森林] 對應老約翰、薩姆。
- **條件類型**：需要力氣、人手的任務用「≥ X」；需要安靜、隱密的任務用「≤ X」；需要拿捏分寸、剛好命中的任務用「X～Y」。
- **緊急任務**只有 2 個回合，難度降一級或提高獎勵。
- **永久任務**可以重複完成，所以獎勵偏低。
- **聲望為負的任務只有 1 張**（下水道裡的交易）。王國榮譽「地下交易」「暗影之主」的黑道路線需要更多這類任務，建議之後補充。
