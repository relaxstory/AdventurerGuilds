# 版本紀錄與設計待辦

> 版本號是**內部標記**，用來記住目前開發到哪裡，不是對外發行的版本。

## 版本號規則

| 情況 | 版本號 |
|---|---|
| **規則調整**（規格書的規則改變） | 升版號，例如 alpha1.1 → alpha1.2 |
| **架構調整**（程式結構、資料格式、開發流程有較大改變） | 升版號 |
| 只有卡片數值或文字更新 | **不升版號**。卡片資料照常發布，使用內部序號（v3、v4…），記錄在 `data/CHANGELOG.md` |
| 錯字、說明文字、介面小修正 | 不升版號 |

- 目前的版本號寫在程式裡（`packages/engine/src/constants.ts` 的 `GAME_VERSION`），試玩網頁的開始畫面和簡易規則會顯示。
- 每次升版號時，在下面新增一節，記錄**規則變更**（附規格書章節和調整依據）以及**架構變更**。

**模擬結果**（詳見 `docs/simulations.md`）：

| 對戰（2 對 2） | 勝率 |
|---|---|
| 任務型 vs 冒險者型 | 33.6% vs 36.5% |
| 任務型 vs 經濟型 | 46.1% vs 19.5% |
| 冒險者型 vs 經濟型 | 49.6% vs 18.9% |

- 任務型以量取勝（完成約 10 項任務）；冒險者型主要靠人才路線的榮譽取勝；經濟型偏弱，道具來源太少，加了格子沒有東西可放。
- 王國競爭模式、四種固定策略的 AI：冒險者型 42.0%、隨機應變 39.4%、任務型 32.4%、經濟型 15.0%。
- 待觀察：經濟型需要道具來源；AI 尚未能執行道具 Combo 與榮譽目標規劃，這部分的平衡還無法驗證。

### 顯示調整

- 王國榮譽（公開時）顯示目標，依路線分組排列。
- 任務的特殊規則顯示在任務內容上方。
- 冒險者卡：種族與職業一行，特質另起一行。
- 「初始公會／已升級」改為「一階公會／二階公會（公會類型）」；整理階段可以選擇公會專精，冒險者型可以選擇從棄置區招募的對象。
- 簡易規則更新：公會專精、道具格 2 格、冒險者上限。

### 錯誤修正

- **學舌鳥複製「對手選擇一項」的能力**（里諾【你好，我可以逮捕你嗎？】、布魯斯與威利【布魯斯！】）：複製產生的選擇會蓋掉原本冒險者的選擇，原本的效果因此消失。改為兩個選擇依序進行；輪到第二個選擇時，若兩個選項都無法執行就略過。介面只顯示可以執行的選項（例如學舌鳥無法翻面）。
- **排隊中的道具捨棄**：道具區連續超過上限時，第二次「選擇捨棄道具」的清單會出現已經不存在的道具。現在輪到時依目前的道具重新判斷。
- 學舌鳥複製菲特時，記錄的文字誤寫成「菲特放在它下方」。

### 架構變更（AI）

- 冒險者已滿時，若酒館有明顯更好的冒險者，會解僱最弱的一名來替換。

- 王國競爭模式（榮譽卡公開）時，招募、解僱、接任務與選擇專精會參考榮譽卡（效果有限，見模擬報告）。

## alpha1.0（2026-11-24）

- 規則：規格書當時的內容（第 1～17 節）為基準。
- 架構：規則引擎（不含卡片能力）、卡片資料流程（從試算表下載、檢查、發布）。
