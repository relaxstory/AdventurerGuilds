# 任務流程相關的卡片文字修改清單（給 AI 助理）

> ✅ **已完成**（2026-11-26）：24 項全部通過設計審查並更新至試算表，已同步回卡片資料；瑞斯教授與希氏炸藥的技能子句已加上時機。

> 依據：規格書 7.1 的新任務流程（alpha1.4）。對象：Google 試算表「卡片設計表」中**實裝與測試**狀態的卡片。
> 每一項的「原文片段」都已經和試算表目前的內容逐格比對過：**確實存在，而且在該格中只出現一次**，可以直接搜尋取代。

## 新任務流程（參考）

```
1. 選擇任務（出動） → ⏸派遣冒險者前 → 2. 派遣（選擇冒險者、支付薪資）→ ⏸建立骰池前
→ 3. 建立骰池 → ⏸擲骰前 → 4. 擲骰 → ⏸確認任務結果前 → 5. 確認任務結果
```

- 時機寫法：「派遣冒險者前」「建立骰池前」「擲骰前」「確認任務結果前」，寫在技能或道具效果的開頭，例如「建立骰池前，橫置此冒險者：……」。
- 「派遣」＝選擇冒險者、支付薪資；「參與」＝建立骰池時在任務中的冒險者（含建立骰池前加入的）。
- 沒有寫時機的主動能力與道具，在冒險階段、任務流程以外使用。

## 修改方式

1. 依「分頁」與「卡片編號」找到那一列，只修改指定的「欄位」（冒險者為**技能**、衍生物為**特徵**、道具為**功能**、任務為**特殊規則**）。
2. 把「原文片段」取代成「修改為」，同一格的其他文字、換行保持不變。
3. 表格中的文字以程式碼格式標示，**不包含**前後的 ` 符號。
4. 找不到原文片段時，**不要猜測修改**，直接回報是哪一項。
5. 不要修改其他欄位、其他分頁，也不要修改「提取用」分頁。
