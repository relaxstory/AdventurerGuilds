# 冒險者文字修改清單（給 AI 助理）

> 依據：`docs/cards.md` 第六節「冒險者文字檢查」。對象：Google 試算表「卡片設計表」的「**冒險者**」分頁，**技能**欄。
> 每一項的「原文片段」都已經和試算表目前的內容逐格比對過：**確實存在，而且在該卡片的技能欄中只出現一次**，可以直接搜尋取代。
> 這些修改只調整文字，不改變目前的規則運作。

## 修改方式

1. 依「卡片編號」找到「冒險者」分頁中的那一列，只修改**技能**欄。
2. 把「原文片段」取代成「修改為」，同一格的其他文字、換行保持不變。
3. 表格中的文字以程式碼格式標示，**不包含**前後的 ` 符號。
4. 找不到原文片段時，**不要猜測修改**，直接回報是哪一項。
5. 不要修改其他欄位、其他分頁，也不要修改「提取用」分頁。

| C61 凱莉的 [動物] 標籤 | 目前沒有任務帶 [動物]，之後補任務時處理 |
| 雙面卡背面種族、職業的「(B)」 | 原始資料的註記，**保留**；試玩網頁顯示時會自動去掉 |

1. 列出每一項的結果：已修改／找不到原文／略過。
2. 第 50 項（C13 萊利的技能名）會改到**技能名稱**。修改後請告訴 Claude，需要同步更新技能子句對照表。

## 給 AI 助理的指示範本

```

https://github.com/relaxstory/AdventurerGuilds/blob/main/docs/adventurer-text-changes.md

規則：
1. 只修改「一」～「三」的項目，「四」不需要修改。
2. 每一處只把「原文片段」取代成「修改為」，同一格的其他文字和換行保持不變。
3. 找不到原文片段時，不要猜測修改，直接回報是哪一項。
4. 不要修改其他欄位、其他分頁與「提取用」分頁。
5. 完成後列出每一項的結果：已修改／找不到原文／略過。
```
